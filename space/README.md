# FongAI

A small (64M parameter) chat assistant you can try in the browser.

FongAI is fine-tuned from the open-source [MiniMind](https://github.com/jingyaogong/minimind) model (Apache-2.0).
Because it is very small, answers can be wrong. Treat it as a toy rather than a source of facts.
